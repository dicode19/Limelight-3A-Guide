# Кольорові та світлоповертаючі пайплайни (Color / Retroreflective Pipelines)

Цей розділ присвячений налаштуванню камери Limelight 3A для швидкого пошуку ігрових елементів та об'єктів за їхнім кольором або за світлоповертаючою стрічкою. Вся логіка обробки базується на колірному просторі HSV (Hue — відтінок, Saturation — насиченість, Value — яскравість), який є набагато стабільнішим до зміни освітлення на арені, ніж звичайний RGB.

## 1. Підготовка базових параметрів (Вкладка Input)

Перш ніж налаштовувати кольори, необхідно оптимізувати якість і швидкість надходження кадрів у вкладці Input:

* **Resolution (Роздільна здатність) і FPS:** Для швидких рухів робота у FTC встановлюйте роздільну здатність 640x480 при 90 кадрах за секунду (FPS) або 320x240 при 90 FPS. Вищий FPS гарантує мінімальну затримку (latency), що критично для автономного періоду.
* **Exposure (Експозиція):** Час відкриття затвора матриці. Утримуйте експозицію якнайнижчою (у межах 600–900). Це повністю «затемнює» фон, стіни арени та сторонні предмети, залишаючи видимими лише яскраві об'єкти. Помилка новачків: залишати високу експозицію, через що під час руху робота об'єкти розмиваються (Motion Blur).
* **Sensor Gain (Чуттливість сенсора):** Цифровий підсилювач яскравості зображення. Використовуйте значення в межах 6–15. Якщо через низьку експозицію картинка стала занадто темною, підніміть Sensor Gain, щоб «витягнути» деталі ігрового елемента без подовження часу експозиції.
* **Black Level Offset (Зміщення чорного рівня):** Апаратне відсікання темних відтінків. Збільшення цього параметра допомагає остаточно прибрати зайві відблиски від стельових ламп спортивної зали або світлодіодних екранів на арені.

## 2. Покрокова інструкція: Налаштування кольорового фільтра (Color Thresholding)

У веб-інтерфейсі камери (`http://limelight.local:5801`) перейдіть до розділу Thresholding. Перемкніть режим перегляду відеопотоку під вікном на «Threshold» (чорно-біла маска): все біле — це об'єкти, які проходять фільтрацію; чорне — повністю відсіюється.

Пояснення повзунків HSV та порядок їх регулювання:

1. **Інструмент «Піпетка» (Thresholding Wands / Eyedropper):**
   * Покладіть ігровий елемент (наприклад, бірюзову кульку) перед камерою на полі.
   * Виберіть інструмент «Eyedropper» і клікніть прямо на зображення кульки у відеопотоці. Камера автоматично заповнить базові діапазони відтінків.
2. **Hue (Відтінок — від 0 до 180):**
   * **Що робить:** Визначає «чистий» колір (0 — червоний, 59 — зелений тощо). Це найважливіший параметр, оскільки він не змінюється при зміні освітленості пікселя.
   * **Як налаштовувати:** Зробіть діапазон відтінків какнайвужчим навколо вибраного кольору. Чим вужчий діапазон Hue ви налаштуєте, тим менше камера реагуватиме на сторонні кольори з аналогічними відтінками на полі (наприклад, кольори форми інших команд або рекламні банери).
   * ⚠️ **Особливість для червоного кольору:** Червоний колір розташовується одночасно на початку (0) і на кінці (180) шкали Hue. Якщо ви шукаєте червоний об'єкт, обов'язково увімкніть опцію Hue Inversion, щоб камера об'єднала обидва кінці шкали.
3. **Saturation (Насиченість — від 0 до 255):**
   * **Що робить:** Показує «чистоту» кольору або те, скільки «білого» в ньому міститься (низька насиченість — блідий колір, висока — чистий).
   * **Як налаштовувати:** Занижуйте мінімальний поріг, якщо елемент у тіні виглядає блідим, і піднімайте, щоб відсіяти сірі чи білі відблиски.
4. **Value (Яскравість/Значення — від 0 до 255):**
   * **Що робить:** Описує темряву кольору або кількість «чорного» в ньому.
   * **Як налаштовувати:** Ніколи не залишайте мінімальне значення на нулеві! Завжди піднімайте нижню межу Value вище нуля, інакше камера сприйматиме абсолютно всі тіні, темні кути та чорні дірки на полі як частину вашої цілі. Піднімайте повзунок доти, доки чорний фон на масці не стане повністю чорним, а ігровий елемент — білим.

## 3. Додаткова фільтрація та очищення контурів (Contour Filtering)

Після порогової обробки кольору камера формує набір контурів навколо знайдених пікселів. Щоб робот не реагував на випадковий смітник чи бліки освітлення, використовуйте фільтри контурів:

* **Area Filter (Фільтр площі):** Задає мінімальний і максимальний розмір об'єкта у відсотках від кадру. Усе, що менше або більше заданого ліміту (наприклад, далеке сміття чи випадковий великий предмет), камера ігноруватиме.
* **Aspect Ratio (Співвідношення сторін):** Якщо ігровий елемент має чітку геометричну форму (наприклад, куля з пропорціями 1:1), звужте цей фільтр, щоб відсіяти занадто «широкі» або «високі» перешкоди.
* **Erosion and Dilation (Ерозія та дилація):**
  * **Erosion** злегка «роз'їдає» краї білих плям, що корисно для видалення дрібного цифрового шуму навколо.
  * **Dilation** злегка розширює білі плями. Використовуйте її, якщо через відблиски на пластиковому ігровому елементі всередині маски з'явилися «дірки» — дилація допоможе «залатати» ці прогалини.

## 4. Інтеграція та базовий код для кольорових пайплайнів (Java / Android Studio)

Після того як пайплайн налаштовано у веб-інтерфейсі та збережено (наприклад, під індексом 0), ви можете зчитувати дані у вашому FTC-проєкті:

```java
package org.firstinspires.ftc.teamcode;

import com.qualcomm.robotcore.eventloop.opmode.LinearOpMode;
import com.qualcomm.robotcore.eventloop.opmode.TeleOp;
import com.qualcomm.hardware.limelightvision.Limelight3A;
import com.qualcomm.hardware.limelightvision.LLResult;

@TeleOp(name = "Limelight Color Tracking", group = "Sensor")
public class LimelightColorTracking extends LinearOpMode {

    private Limelight3A limelight;

    @Override
    public void runOpMode() {
        // 1. Ініціалізація камери згідно з назвою в конфігурації Robot Controller ("limelight")
        limelight = hardwareMap.get(Limelight3A.class, "limelight");
        
        telemetry.setMsTransmissionInterval(11);
        
        // 2. Перемикання на потрібний кольоровий пайплайн (наприклад, пайплайн 0)
        limelight.pipelineSwitch(0);
        
        // 3. Запуск опитування камери
        limelight.start();

        telemetry.addData("Статус", "Limelight активовано. Очікування старту...");
        telemetry.update();

        waitForStart();

        while (opModeIsActive()) {
            // 4. Отримання останнього актуального результату від камери
            LLResult result = limelight.getLatestResult();

            // 5. Перевірка: чи є результат і чи знайдено валідну ціль
            if (result != null && result.isValid()) {
                double tx = result.getTx(); // Горизонтальне зміщення цілі від центру кадру (в градусах)
                double ty = result.getTy(); // Вертикальне зміщення цілі від центру кадру (в градусах)
                double ta = result.getTa(); // Площа цілі у відсотках від усього кадру (0 - 100%)

                telemetry.addData("Ціль знайдено", "Так");
                telemetry.addData("Горизонталь (tx)", tx);
                telemetry.addData("Вертикаль (ty)", ty);
                telemetry.addData("Площа об'єкта (ta)", ta + "%");
            } else {
                telemetry.addData("Ціль знайдено", "Ні");
            }

            telemetry.update();
        }

        // Зупинка камери при виході з програми
        limelight.stop();
    }
}
