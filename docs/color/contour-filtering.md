# Contour Filtering and Sorting

Після того як колірна маска відсіяла зайві пікселі, камера об'єднує їх у контури. Для змагань FTC це життєво необхідно, щоб робот ігнорував випадкове сміття на полі, деталі від роботів суперників чи сторонні відблиски.

### Основні фільтри контурів
* **Area Filter (Фільтр площі):** Задає мінімальний і максимальний розмір знайденого об'єкта у відсотках від усього кадру. Дозволяє ігнорувати далекі дрібні об'єкти або випадкові великі перешкоди.
* **Aspect Ratio (Співвідношення сторін):** Допомагає відсіювати контури, які не відповідають геометричній формі ігрового елемента (наприклад, занадто витягнуті предмети).
* **Sorting (Сортування контурів):** Якщо камера бачить кілька ігрових елементів одночасно, сортування дозволяє вибрати найближчий до центру робота, найбільший за площею або найближчий за дистанцією об'єкт для пріоритетного захоплення під час автономного та телеоп періоду FTC.
