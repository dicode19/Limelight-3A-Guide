# Колірна фільтрація (Color Thresholding)

Колірна фільтрація (Thresholding) — один із найважливіших етапів більшості алгоритмів комп'ютерного зору. Вона полягає в обробці зображення та відкиданні всіх пікселів, колір яких не відповідає заданому діапазону.

У результаті фільтрації формується бінарне зображення, у якому кожен піксель має лише два стани: активний (ON) або неактивний (OFF).

У конвеєрах розпізнавання кольорових об'єктів (Color Blob) та світловідбивних цілей (Retroreflective Pipelines) цей етап є найважливішим, оскільки саме він визначає, які об'єкти будуть передані на подальшу обробку.

Для налаштування колірної фільтрації Limelight використовує колірну модель HSV (Hue, Saturation, Value), яка дає змогу задавати діапазони відтінку, насиченості та яскравості.

## Відеопотік (Video Feed)

Цей параметр визначає, яке саме зображення передаватиметься через MJPEG-сервер для відображення у відеопотоці Limelight.

Під час налаштування HSV-фільтрації рекомендується вибрати зображення **Threshold**. Воно показує результат колірної фільтрації та дає змогу відразу побачити, які пікселі проходять задані порогові значення.

Це особливо корисно під час налаштування діапазонів HSV, оскільки можна спостерігати, як зміна кожного параметра впливає на результат розпізнавання.

## Інструменти колірної фільтрації (Thresholding Wands)

Інструменти Thresholding Wands дають змогу натискати на окремі ділянки відеопотоку Limelight для автоматичного налаштування HSV-фільтрації.

Доступні три інструменти:

### Піпетка (Eyedropper)

Інструмент Eyedropper автоматично встановлює центральні значення параметрів HSV відповідно до кольору вибраного пікселя.

Це дає змогу швидко визначити початкові значення для подальшого налаштування колірного діапазону.

### Додавання кольору (Add)

Інструмент Add змінює діапазони HSV так, щоб вибраний піксель відповідав умовам фільтрації.

Використовується для додавання кольорів, які не потрапляють у поточний діапазон фільтрації.

### Віднімання кольору (Subtract)

Інструмент Subtract змінює діапазони HSV так, щоб вибраний піксель більше не проходив колірну фільтрацію.

Використовується для усунення сторонніх кольорів, які помилково розпізнаються як частина цілі.

## Відтінок (Hue)

Hue визначає основний колір пікселя без урахування його яскравості або насиченості.

Наприклад:
- Значення Hue = 0 відповідає чистому червоному кольору.
- Значення Hue = 1/3 (59 на повзунку) відповідає чистому зеленому кольору.

Відтінок є особливо корисним параметром, оскільки він не змінюється під час збільшення або зменшення яскравості пікселя.

Це один із найважливіших параметрів, який потрібно налаштовувати під час колірної фільтрації.

**Рекомендація:** намагайтеся зробити діапазон Hue якомога вужчим, зберігаючи при цьому всі необхідні пікселі цілі. Це допоможе уникнути помилкового розпізнавання сторонніх об'єктів під час переходу від лабораторних умов до справжнього ігрового поля FRC.

## Насиченість (Saturation)

Saturation визначає ступінь насиченості кольору, тобто наскільки він є чистим.

Іншими словами, цей параметр показує, наскільки колір виглядає бляклим або розмитим, а також скільки білого кольору в ньому міститься.

- Низьке значення Saturation відповідає майже білому або бляклому кольору.
- Високе значення Saturation відповідає насиченому, чистому кольору.

Налаштування цього параметра допомагає відокремити насичені кольори цілі від бляклих або майже білих ділянок зображення.

## Яскравість (Value)

Value визначає темність або яскравість кольору, тобто кількість чорного в ньому.

- Низьке значення Value відповідає майже чорному кольору.
- Високе значення Value відповідає світлому кольору.

**Важливо:** мінімальне значення Value потрібно обов'язково збільшити відносно нуля. Це запобігає проходженню чорних пікселів через конвеєр обробки зображення.

Якщо залишити мінімальне значення на нулі, темні ділянки зображення також можуть потрапляти до результатів колірної фільтрації, створюючи зайві контури та перешкоди для розпізнавання цілі.

## Ерозія та дилатація (Erosion and Dilation)

Erosion та Dilation — це операції морфологічної обробки зображення, які використовуються для коригування результатів HSV-фільтрації.

### Ерозія (Erosion)

Erosion незначно зменшує області пікселів, які пройшли HSV-фільтрацію.

Це корисно, коли після налаштування колірного діапазону через фільтр проходить занадто багато сторонніх об'єктів.

Ерозія допомагає зменшити видимі області розпізнаних об'єктів та усунути невеликі зайві фрагменти.

### Дилатація (Dilation)

Dilation незначно збільшує області пікселів, які пройшли HSV-фільтрацію.

Її рекомендується використовувати для заповнення невеликих отворів усередині розпізнаних об'єктів та відновлення цілісності їхніх областей.

## Інверсія відтінку (Hue Inversion)

Hue Inversion використовується для розпізнавання червоних цілей.

Особливість червоного кольору полягає в тому, що він розташований одночасно на початку та наприкінці діапазону Hue.

Через це стандартний діапазон відтінку може не охоплювати всі значення червоного кольору одним безперервним інтервалом.

Увімкнення Hue Inversion дає змогу правильно обробляти цей особливий випадок і розпізнавати червоні об'єкти, значення відтінку яких знаходяться по обидва боки діапазону Hue.
