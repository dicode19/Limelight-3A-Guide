# Additional Theory (Теоретичні основи)

Розуміння базових принципів роботи комп'ютерного зору в умовах реальної арени FTC допомагає уникнути типових помилок налаштування.

### Чому використовується HSV, а не RGB?
Простір RGB надмірно залежить від змін освітлення (наприклад, яскравих світлодіодних екранів на арені чи різного рівня освітленості в різних кутах поля). Колірний простір **HSV** ( Hue, Saturation, Value ) розділяє чистий відтінок кольору та його яскравість, що робить його в рази стабільнішим для робототехніки в умовах змагань.

### Швидкодія та затримка (Latency)
У швидких динамічних матчах FTC кожна мілісекунда затримки впливає на точність наведені під час автономного періоду. Використання оптимізованих параметрів експозиції та високого FPS (наприклад, 90 FPS) дозволяє уникнути розмиття руху (Motion Blur) та забезпечити миттєву реакцію системи керування робота.
