# Відстеження AprilTags

Limelight може розпізнавати AprilTags та визначати їхнє положення відносно камери. Для базового відстеження використовуються стандартні значення `tx`, `ty` та `ta`. Для 3D-відстеження можна використовувати `botpose` і `campose`, а для роботи з кількома мітками — JSON-результати.

## Швидкий початок для FTC

Щоб налаштувати відстеження AprilTags:

1. Відкрий вкладку **Input** та зміни `Pipeline Type` на **Fiducial Markers**.
2. Для 3D-відстеження використовуй найвищу доступну роздільну здатність. Для звичайного 2D-відстеження можна використовувати `640×480`.
3. У вкладці **Standard** встанови сімейство міток `AprilTag Classic 36h11`.
4. У вкладці **Input** встанови `Black Level` на `0`.
5. Налаштуй `Gain` та `Exposure`, щоб мітки чітко розпізнавалися навіть під час руху робота.
6. За потреби збільш `Detector Downscale`, щоб підвищити частоту обробки кадрів.
7. Якщо потрібно одночасно використовувати 2D- та 3D-відстеження, задай пріоритетний ID мітки через NetworkTables.
8. У налаштуваннях Limelight перевір номер команди та мережеві параметри.

Після цього можна використовувати `tx` і `ty` з NetworkTables у програмі робота.

## Поради

Для надійного відстеження AprilTags враховуй такі рекомендації:

- Розміщуй мітки якомога рівніше, без нахилів і деформацій.
- Встановлюй Limelight вище або нижче рівня міток і трохи нахиляй камеру вгору чи вниз.
- Уникай ситуацій, коли камера дивиться на мітку прямо спереду. Невеликий кут огляду допомагає зменшити помилки визначення орієнтації мітки.
- Забезпеч достатнє освітлення, щоб камера могла чітко розпізнавати контрастні елементи мітки.

На якість відстеження впливають кілька параметрів:

- **Роздільна здатність камери.** Її збільшення підвищує точність і стабільність 3D-визначення, а також може збільшити дальність розпізнавання. Водночас зменшується частота обробки кадрів.
- **Detector Downscale.** Збільшення цього значення підвищує частоту обробки кадрів, але може зменшити дальність розпізнавання.
- **Exposure.** Зменшення часу експозиції знижує розмиття зображення під час руху робота, але може зменшити дальність розпізнавання.
- **Brightness і Contrast.** Зменшення яскравості та контрастності зазвичай підвищує швидкість обробки, але може зменшити дальність розпізнавання.
- **Sensor Gain.** Збільшення підсилення сенсора дає змогу зробити зображення яскравішим без збільшення часу експозиції. Однак надто високий Gain може погіршити стабільність 3D-визначення та відстеження.

## Вкладка Input

У вкладці **Input** можна змінювати параметри вихідного зображення камери перед його обробкою.

Для відстеження AprilTags:

- Встанови `Pipeline Type` на **Fiducial Markers**.
- Встанови `Black Level` на `0`.

Далі потрібно налаштувати `Sensor Gain` та `Exposure`.

Головна мета — отримати чітке зображення міток за мінімального часу експозиції. Це зменшує розмиття під час руху робота. Зазвичай для цього використовують високий рівень підсилення сенсора.

Для звичайного 2D-відстеження можна спочатку збільшити `Sensor Gain`, а потім поступово підвищувати `Exposure`, доки мітки не почнуть стабільно розпізнаватися.

Якщо Limelight не розпізнає мітки, перевір правильність вибраного сімейства у вкладці **Standard**.

## Вкладка Standard

### Family

Визначає сімейство AprilTags, яке використовуватиметься для розпізнавання.

Для FIRST Tech Challenge використовується сімейство **AprilTag 36h11**.

### Marker Size

Визначає очікуваний розмір міток у міліметрах.

Вказуй фактичний розмір мітки відповідно до правил поточного сезону FTC або розміру власної мітки.

Важливо: для AprilTag 36h11 розмір визначається за зовнішніми краями внутрішньої чорної рамки, а не за зовнішнім білим полем мітки.

### Detector Downscale

Збільшення цього параметра може суттєво підвищити швидкість обробки зображення.

Однак надто велике значення може зменшити дальність розпізнавання міток. Підбирай його експериментально, щоб знайти баланс між швидкістю та дальністю.

### ID Filters

Дозволяє вказати конкретні ID міток, які потрібно розпізнавати.

ID задаються списком чисел через кому, наприклад:

`0,1,2`

Це допомагає відфільтрувати непотрібні мітки та зменшити кількість хибних розпізнавань.

Якщо роботу потрібна лише одна конкретна мітка, вкажи її ID.

### Cropping

Дозволяє обрізати частину зображення, яку Limelight не повинен обробляти.

Це може суттєво підвищити швидкість обробки, оскільки камера аналізуватиме лише потрібну область.

Для динамічної зміни області обрізання під час роботи можна використовувати ключ `crop` у NetworkTables.

### Multi-Target Sorting and Grouping

Дозволяє групувати та сортувати кілька знайдених міток за заданими параметрами.

Це корисно, коли камера одночасно бачить декілька AprilTags. Наприклад, за допомогою фільтра `Area` можна відкидати занадто малі мітки, які знаходяться далеко від камери.
