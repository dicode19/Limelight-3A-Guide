# Інструмент створення карт та генератор міток

Limelight надає два онлайн-інструменти для роботи з AprilTags:

- **Map Builder** — 3D-редактор для створення карт поля з розташуванням AprilTags.
- **AprilTag Generator** — генератор PDF-файлів із мітками заданого розміру та ID.

Ці інструменти корисні для підготовки власного поля, створення карт локалізації та друку AprilTags.

## Map Builder

**Map Builder** — онлайн-редактор для створення тривимірних карт AprilTag. Він дає змогу додавати мітки, задавати їхнє положення та орієнтацію, а також експортувати готову карту у форматі `.fmap`.

Відкрити інструмент можна за посиланням:

[Limelight AprilTag Map Builder](https://tools.limelightvision.io/map-builder)

### Основні можливості

**1. Вибір типу карти**

Map Builder підтримує різні системи координат ігрового поля, зокрема:

- `FTC` — стандартна система координат поля FTC.
- `FTC Diamond` — альтернативна система координат FTC.

Вибирай тип відповідно до системи координат, у якій створюється карта.

**2. Розміри поля**

Параметри `Field Length` та `Field Width` визначають довжину й ширину поля в метрах.

Вказуй фактичні розміри поля відповідно до офіційної документації FTC або вимірювань власного тренувального поля.

**3. Додавання AprilTags**

За допомогою `Add Marker` можна додавати мітки на поле.

Для кожної мітки потрібно визначити:

- ID;
- фізичний розмір;
- положення на полі;
- орієнтацію відносно поля.

Розташовуй мітки відповідно до їхнього реального встановлення. Неправильні координати або орієнтація призведуть до помилок локалізації.

**4. Додавання моделі поля**

Map Builder підтримує завантаження додаткових матеріалів:

- `Field Image` — зображення поля, яке можна використовувати як основу для розміщення міток.
- `Field Mesh (.glb)` — тривимірна модель поля у форматі GLB.

Ці матеріали допомагають точніше розміщувати AprilTags та перевіряти їхнє положення у 3D-просторі.

**5. Переміщення та обертання об'єктів**

Для редагування положення міток доступні режими:

- `Translate` — переміщення об'єкта.
- `Rotate` — обертання об'єкта.
- `Local Space` — редагування відносно локальних осей об'єкта.
- `World Space` — редагування відносно глобальних осей поля.

Під час роботи з мітками перевіряй не лише їхнє положення, а й напрямок поверхні. Камера повинна отримувати правильну орієнтацію мітки для коректної локалізації.

**6. Керування редактором**

У Map Builder передбачене керування клавіатурою:

| Клавіші | Дія |
|---|---|
| `W`, `A`, `S`, `D` | Переміщення в 3D-просторі |
| `Q`, `E` | Додаткове переміщення по вертикалі |
| `Spacebar` | Керування переміщенням |
| Стрілки | Переміщення та навігація |

Набір дій може залежати від активного режиму редактора.

### Створення карти для FTC

Для створення власної карти поля виконай такі кроки:

1. Відкрий [Map Builder](https://tools.limelightvision.io/map-builder).
2. Вибери відповідний тип карти FTC.
3. Вкажи довжину та ширину поля в метрах.
4. За потреби завантаж зображення або 3D-модель поля.
5. Додай AprilTags та вкажи їхні ID.
6. Розмісти мітки відповідно до реальних координат на полі.
7. Налаштуй орієнтацію кожної мітки.
8. Перевір розташування всіх міток у 3D-візуалізаторі.
9. Завантаж готовий файл через `Download`.

Результатом буде файл `.fmap`, який можна завантажити в Limelight для локалізації робота.

**Важливо:** перед використанням карти перевір її відповідність поточному сезону FTC. Особливу увагу приділи ID, розмірам та координатам AprilTags.

## AprilTag Generator

**AprilTag Generator** — онлайн-інструмент для створення PDF-файлів із мітками, які можна надрукувати та використовувати у власних проєктах.

Відкрити генератор можна за посиланням:

[Limelight AprilTag Generator](https://tools.limelightvision.io/apriltag-generator)

### Налаштування генератора

**1. Paper Size**

Вибір формату паперу для друку. Наприклад, US Letter або інший доступний формат.

**2. Family**

Вибір сімейства AprilTags.

Для FTC зазвичай використовується:

`AprilTag Classic 36h11`

**3. Size (mm)**

Фізичний розмір мітки в міліметрах.

Вказуй точний розмір відповідно до правил FTC або вимог власного проєкту.

**4. Tag ID Ranges**

Діапазон ID міток, які потрібно згенерувати.

Можна вказати один ID або діапазон номерів.

**5. Border Type**

Тип рамки навколо мітки.

Рекомендовано використовувати `None`, якщо немає інших вимог до друку.

### Створення та друк міток

1. Відкрий AprilTag Generator.
2. Вибери формат паперу.
3. Встанови сімейство `AprilTag Classic 36h11`.
4. Вкажи потрібний розмір у міліметрах.
5. Задай діапазон ID.
6. Вибери тип рамки.
7. Натисни `Generate`.
8. Завантаж PDF та надрукуй мітки.

Після друку перевір фактичний розмір міток за допомогою лінійки. Масштаб друку має бути 100% — без автоматичного припасування до сторінки.

**Важливо:** генератор призначений для створення власних міток. Якщо ти готуєшся до офіційних змагань FTC, використовуй мітки, які відповідають вимогам поточного сезону. Не замінюй ними офіційні елементи поля.

## Рекомендації для FTC

- Для офіційного поля використовуй актуальну карту AprilTag поточного сезону, якщо вона доступна.
- Для тренувального поля можна створити власну карту через Map Builder.
- Перевіряй фізичний розмір надрукованих міток.
- Не змінюй ID офіційних міток.
- Перевіряй положення та орієнтацію міток у 3D-візуалізаторі.
- Після завантаження карти перевір правильність локалізації робота через Limelight.

Докладніше про формат карт читай у розділі [Специфікація карт AprilTag](apriltag-map-specification.md).
