# Color Thresholding

Фільтрація за кольором є критично важливим етапом для роботи з кольоровими блоками та світлоповертаючими елементами на арені FTC. Вона дозволяє перетворити початкове зображення на чорно-білу маску, де цільові об'єкти позначені білим кольором, а все зайве відсіюється.

### Відеопотік та піпетки (Thresholding Wands)
* **Video Feed:** У веб-інтерфейсі камери перемикайте режим перегляду на **«Threshold»**, щоб налаштовувати маску в реальному часі.
* **Eyedropper / Wands:** Інструменти автоматичного налаштування діапазонів HSV шляхом кліку безпосередньо по ігровому елементу у вікні камери.

### Параметри HSV
* **Hue (Відтінок):** Визначає «чистий» колір (0 — червоний, 59 — зелений тощо). Найголовніший параметр, що не залежить від зміни освітленості на арені FTC. Максимально звужуйте діапазон, щоб камера ігнорувала форму суперників чи рекламні банери.
  * ⚠️ *Особливість для червоного кольору:* Оскільки червоний знаходиться на початку (0) і на кінці (180) шкали, обов'язково вмикайте **Hue Inversion**.
* **Saturation (Насиченість):** Показує чистоту кольору та наявність «білого». Допомагає відсіювати бліді відблиски.
* **Value (Яскравість):** Відповідає за кількість «чорного». Уникайте нульових значень нижньої межі, щоб кути поля та тіні не розпізнавалися як ігрові елементи FTC.

### Очищення маски
* **Erosion (Ерозія) та Dilation (Дилація):** Використовуйте ерозію для придушення дрібного цифрового шуму, а дилацію — щоб «залатати» чорні прогалини та дірки на пластикових ігрових елементах через бліки під час матчу.
