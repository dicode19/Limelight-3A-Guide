# Початок роботи з нейромережами

Нейромережеві пайплайни Limelight дають змогу розпізнавати об'єкти та класифікувати зображення за допомогою технологій машинного навчання.

На відміну від звичайних пайплайнів, де потрібно вручну налаштовувати кольори, контури та інші параметри, нейромережі навчаються самостійно знаходити потрібні ознаки на зображеннях.

У FIRST Tech Challenge (FTC) це можна використовувати для:

- розпізнавання ігрових елементів;
- визначення типу об'єкта;
- підрахунку об'єктів у певній зоні;
- визначення наявності ігрового елемента в механізмі робота;
- розпізнавання стану окремих елементів поля.

## Апаратне забезпечення

**Важливо для Limelight 3A:** ця модель не підтримує Google Coral USB Accelerator. Нейромережеві моделі виконуються безпосередньо на CPU камери.

Тому для Limelight 3A потрібно використовувати моделі, сумісні з CPU Runtime.

Для роботи з FTC:

1. Підключи Limelight 3A до USB 3.0 порту Control Hub.
2. Переконайся, що камера визначається системою.
3. Відкрий вебінтерфейс Limelight.
4. Перейди до налаштувань пайплайна.

## Типи нейромережевих пайплайнів

Limelight підтримує два основні типи нейромереж:

- **Neural Detector** — знаходить об'єкти на зображенні, визначає їхні класи та положення.
- **Neural Classifier** — класифікує зображення або його вибрану область, визначаючи, до якого класу вона належить.

### Neural Detector

Neural Detector використовується для пошуку та розпізнавання об'єктів на зображенні.

На виході нейромережа повертає:

- клас розпізнаного об'єкта;
- координати обмежувальної рамки (Bounding Box);
- рівень впевненості (Confidence).

Кожен знайдений об'єкт має власну обмежувальну рамку, яка показує його положення на зображенні.

**Приклад використання у FTC:** робот має знайти ігровий елемент на полі. Neural Detector може визначити його положення та передати координати програмі робота для подальшого наведення.

#### Початкове налаштування

1. Переконайся, що в Limelight завантажена сумісна нейромережева модель.
2. У вкладці **Input** зміни `Pipeline Type` на `Neural Detector`.
3. Встанови `Runtime Engine` на `CPU`.
4. Перевір, чи модель завантажилася та почала обробляти зображення.
5. Налаштуй повзунок `Confidence Threshold`, щоб змінити мінімальний рівень впевненості для розпізнавання.
6. За допомогою `Crop` обмеж область зображення, у якій потрібно шукати об'єкти.

Параметр `Confidence Threshold` визначає, наскільки впевнено нейромережа має розпізнати об'єкт, щоб додати його до результатів.

Збільшення порога зменшує кількість сумнівних розпізнавань, але може призвести до пропуску справжніх об'єктів.

Зменшення порога дає змогу знаходити більше об'єктів, але збільшує ймовірність хибних спрацьовувань.

Параметр `Crop` дає змогу ігнорувати частини зображення, які не потрібні для розпізнавання. Це може зменшити кількість помилкових виявлень та навантаження на систему.

### Neural Classifier

Neural Classifier використовується для визначення класу зображення або вибраної області.

На відміну від Detector, класифікатор не шукає координати кожного об'єкта на зображенні. Він визначає, до якого з попередньо навчених класів належить зображення.

**Приклад використання у FTC:** камера встановлена всередині механізму робота та спрямована на ігровий елемент. Класифікатор може визначити, чи є всередині механізму потрібний елемент, або розрізняти кілька його типів.

#### Початкове налаштування

1. Переконайся, що в Limelight завантажена сумісна модель класифікатора.
2. У вкладці **Input** зміни `Pipeline Type` на `Neural Classifier`.
3. Встанови `Runtime Engine` на `CPU`.
4. Перевір роботу моделі на зображенні з камери.
5. За допомогою `Crop` налаштуй область зображення, яку потрібно передавати нейромережі.

Параметр `Crop` особливо важливий для класифікатора. Намагайся залишати в кадрі лише ті об'єкти та ознаки, які потрібні для визначення класу.

Чим менше зайвих елементів потрапляє в область аналізу, тим простіше нейромережі правильно класифікувати зображення.

## Продуктивність нейромереж

Оскільки Limelight 3A виконує нейромережеві обчислення на CPU, швидкість роботи залежить від складності моделі, розміру зображення та інших параметрів.

За документацією Limelight, для CPU-моделей на пристроях серії Limelight 3 можна орієнтуватися приблизно на:

- Neural Detector — близько 10 FPS;
- Neural Classifier — близько 15–18 FPS.

Фактична швидкість може відрізнятися залежно від моделі та налаштувань.

Для підвищення продуктивності:

- використовуй область `Crop`, щоб зменшити кількість зайвих даних;
- обирай моделі, навчені для конкретного завдання;
- не використовуй надмірно складні моделі;
- перевіряй фактичну частоту обробки кадрів після завантаження моделі.

## Навчання власних моделей

Limelight дає змогу створювати власні нейромережеві моделі для конкретних завдань.

Для цього можна використовувати Roboflow та інструмент Limelight Neural Network Trainer.

Загальний процес:

1. Збери зображення об'єктів, які потрібно розпізнавати.
2. Підготуй набір даних та познач об'єкти.
3. Навчи модель за допомогою Neural Network Trainer.
4. Завантаж отриману модель.
5. Перевір її роботу на Limelight 3A.

Для Neural Detector використовується розмітка об'єктів обмежувальними рамками (Bounding Boxes), а для Neural Classifier — зображення, розподілені за класами.
