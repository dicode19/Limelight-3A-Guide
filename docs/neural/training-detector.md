# Навчання власної моделі Neural Detector

За допомогою **Roboflow** та **Limelight Neural Network Trainer** можна створити власну модель для розпізнавання об'єктів на Limelight 3A.

На відміну від Neural Classifier, який класифікує зображення або його частину, **Neural Detector знаходить об'єкти на зображенні**, визначає їхні класи та малює навколо них рамки (Bounding Boxes).

Для FTC це можна використовувати, наприклад, для виявлення ігрових елементів, їх пошуку на полі та визначення координат відносно камери.

Процес складається з трьох основних етапів:

1. Створення та розмітка набору зображень у Roboflow.
2. Навчання моделі через Limelight Neural Network Trainer.
3. Завантаження моделі на Limelight 3A.

## 1. Створення набору даних

Для навчання моделі потрібен набір зображень із розміченими об'єктами. Кожен об'єкт має бути обведений прямокутною рамкою — **Bounding Box**, а також мати назву класу (Class Label).

Для створення набору даних можна використовувати [Roboflow](https://roboflow.com/) або знайти готовий набір у [Roboflow Universe](https://universe.roboflow.com/).

### Збір зображень

Збирайте зображення об'єктів, які робот має розпізнавати під час змагань. Важливо, щоб набір даних був різноманітним.

Рекомендується додавати зображення:
- з різних кутів і відстаней;
- за різного освітлення;
- на різному фоні;
- з частково закритими об'єктами;
- з кількома об'єктами в кадрі;
- у реальних умовах, близьких до умов на полі FTC.

Набір даних має відображати всі умови, у яких камера працюватиме на роботі.

### Розмітка зображень

Після завантаження зображень у Roboflow потрібно позначити об'єкти, які модель має знаходити.

Для цього:
1. Створіть новий проєкт у Roboflow.
2. Виберіть тип проєкту **Object Detection**.
3. Завантажте зображення.
4. Відкрийте кожне зображення та обведіть потрібні об'єкти рамками.
5. Призначте кожній рамці відповідний клас.
6. Перевірте розмітку та збережіть зміни.

**Важливо:**
- Рамки мають точно охоплювати об'єкти.
- Використовуйте однаковий принцип розмітки для всіх зображень.
- Якщо об'єкт частково закритий, позначайте лише його видиму частину.
- Назви класів використовуйте малими літерами.
- Намагайтеся не створювати зайвих класів.

### Підготовка набору даних

Після розмітки можна використовувати інструменти Roboflow для збільшення різноманітності набору даних — **Data Augmentation**.

Наприклад:
- поворот зображень;
- зміна яскравості;
- обрізання;
- масштабування;
- зміна контрастності.

Використовуйте лише ті перетворення, які відповідають реальним умовам роботи робота. Наприклад, якщо потрібно розрізняти червоні та сині об'єкти, не варто застосовувати перетворення, що сильно змінюють їхні кольори.

Після підготовки набору даних:
1. Натисніть **Generate**.
2. Виберіть потрібні параметри набору даних.
3. Перейдіть до завантаження — **Download Dataset**.
4. Виберіть формат **TensorFlow TFRecord**.
5. Завантажте архів із набором даних.

Для навчання Limelight потрібен архів `.tfrecord` у ZIP-форматі.

Завантажте цей архів на Google Drive.

## 2. Навчання моделі

Для навчання використовується [Limelight Neural Network Trainer](https://tools.limelightvision.io/neural-network-trainer).

Відкрийте інструмент і вставте посилання на архів із набором даних, який ви завантажили на Google Drive.

### Налаштування навчання

Перед запуском перевірте доступ до файлу на Google Drive. Він має бути доступний для перегляду за посиланням або для відповідного облікового запису, який використовує інструмент навчання.

У полі для посилання вставте посилання на архів `.tfrecord`.

Основні параметри:

- **Training Steps** — кількість кроків навчання.
  - `4000` — для швидкої перевірки моделі.
  - `20000` — для спроби покращити точність після початкового тестування.
- **Platform** — платформа, для якої створюється модель.

Для Limelight 3A виберіть **Limelight CPU / Google Coral**.

> **Увага!** Для FTC з Limelight 3A використовується CPU. Не вибирайте Hailo 8 або Hailo 8L — ці платформи призначені для інших моделей Limelight.

Після налаштування натисніть **Start Training**.

Навчання може тривати до 5 годин. Після завершення натисніть **Download**, щоб завантажити архів із готовою моделлю.

## 3. Завантаження моделі на Limelight 3A

Після завантаження розпакуйте архів. У ньому будуть файли навченої моделі.

Для FTC з Limelight 3A потрібні:

- **8-bit TensorFlow Lite модель** (`.tflite`);
- **`labels.txt`** — файл із назвами класів, які розпізнає модель.

Завантажте ці файли на Limelight 3A через його вебінтерфейс.

Після завантаження:

1. Відкрийте налаштування Neural Detector.
2. Виберіть завантажену модель.
3. Знайдіть параметр **Runtime Engine**.
4. Змініть значення з `coral` на `cpu`.
5. Перевірте, чи модель правильно розпізнає об'єкти.

> **Важливо для FTC:** Limelight 3A використовує CPU для запуску Neural Detector. Тому потрібно завантажувати саме 8-bit `.tflite` модель і встановити Runtime Engine у значення `cpu`.

## 4. Перевірка роботи моделі

Після налаштування відкрийте перегляд зображення з камери Limelight.

Перевірте:
- чи знаходить модель потрібні об'єкти;
- чи правильно визначає їхні класи;
- чи точно розташовані рамки навколо об'єктів;
- чи не плутає модель різні класи;
- чи стабільно працює розпізнавання за різного освітлення та відстані.

Якщо модель часто помиляється, варто доповнити набір даних новими зображеннями, перевірити розмітку та повторити навчання.
