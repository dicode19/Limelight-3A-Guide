# Навчання власної моделі класифікатора

**Google Teachable Machine** — вебінструмент, який дає змогу створювати власні моделі класифікації зображень без програмування та глибоких знань машинного навчання.

За його допомогою можна навчити Limelight розпізнавати різні типи об'єктів або визначати їхній стан.

Наприклад, у FTC класифікатор можна використовувати для:

- визначення кольору ігрового елемента;
- розпізнавання типу об'єкта;
- визначення наявності ігрового елемента в механізмі;
- розрізнення порожнього та заповненого контейнера;
- визначення стану певного елемента робота.

Для створення моделі використовуватимемо Google Teachable Machine.

Посилання: [https://teachablemachine.withgoogle.com/](https://teachablemachine.withgoogle.com/)

## 1. Підготовка набору даних (Data Collection)

Перед навчанням потрібно зібрати зображення об'єктів, які класифікатор має розпізнавати.

Кожна категорія об'єктів утворює окремий клас (Class).

Наприклад, якщо потрібно розрізняти червоні та сині ігрові елементи, створи два класи:

- `Red` — червоні елементи.
- `Blue` — сині елементи.

За потреби можна додати клас `Background`, який міститиме зображення без потрібних об'єктів.

### Вимоги до зображень

Для якісного навчання важливо дотримуватися кількох правил:

- **Збалансованість.** Кількість зображень у кожному класі має бути приблизно однаковою.
- **Різноманітність.** Використовуй різні кути огляду, відстані, освітлення та фони.
- **Реальні умови.** Збирай зображення в умовах, максимально наближених до тих, у яких працюватиме камера на роботі.
- **Якість.** Переконайся, що об'єкти добре видно та вони правильно віднесені до відповідних класів.

Не використовуй лише однакові фотографії об'єкта. Якщо всі навчальні зображення зроблені під одним кутом і на одному фоні, модель може погано працювати в інших умовах.

Рекомендовано починати щонайменше з 30 зображень на клас, а для складніших завдань збирати значно більше прикладів.

## 2. Навчання за допомогою Teachable Machine

Відкрий [Google Teachable Machine](https://teachablemachine.withgoogle.com/).

Виконай такі кроки:

1. Натисни **Get Started**.
2. Вибери **Image Project**.
3. Вибери **Standard image model**.
4. Створи потрібну кількість класів за допомогою **Add a class**.
5. Дай кожному класу зрозумілу назву.
6. Додай зображення до відповідних класів через **Upload** або **Webcam**.
7. Переконайся, що всі зображення розподілені правильно.
8. Натисни **Train Model**.

Після цього Teachable Machine почне навчання моделі.

Не закривай сторінку, поки процес не завершиться.

### Перевірка моделі

Після навчання можна перевірити роботу класифікатора безпосередньо у браузері.

Для цього:

1. Увімкни вхідні дані в розділі **Preview**.
2. Вибери джерело зображення — Webcam або File.
3. Покажи камері об'єкт або завантаж тестове зображення.
4. Перевір, який клас визначила модель.
5. Оціни рівень впевненості (Confidence) для кожного класу.

Для перевірки використовуй зображення, яких не було в навчальному наборі. Це допоможе зрозуміти, чи модель справді навчилася розпізнавати об'єкти, а не просто запам'ятала приклади.

Якщо результати неправильні, додай більше різноманітних зображень і повтори навчання.

## 3. Експорт моделі

Після успішного навчання потрібно експортувати модель у форматі, сумісному з Limelight 3A.

1. Натисни **Export Model**.
2. Перейди до вкладки **TensorFlow Lite**.
3. Вибери тип конвертації **Quantized**.
4. Натисни **Download**.

<note>
**Важливо для FTC:** під час експорту для Limelight 3A вибирай саме `Quantized`, а не `EdgeTPU`.

`EdgeTPU` призначений для Limelight із Google Coral Accelerator. Limelight 3A використовує CPU для виконання нейромережевих моделей.
</note>

Після завантаження ти отримаєш файл моделі TensorFlow Lite (`.tflite`).

## 4. Завантаження моделі в Limelight 3A

Після експорту модель потрібно завантажити в Limelight.

1. Підключися до вебінтерфейсу Limelight.
2. Вибери потрібний пайплайн.
3. У вкладці **Input** встанови `Pipeline Type` на `Neural Classifier`.
4. Завантаж отриманий файл `.tflite` у поле моделі.
5. Встанови `Runtime Engine` на `CPU`, якщо цей параметр доступний у твоїй версії Limelight OS.
6. Збережи налаштування та перевір результат класифікації.

Після завантаження перевір, чи модель правильно визначає класи на зображеннях із камери.

## 5. Рекомендації для FTC

Щоб отримати стабільні результати на роботі:

- Збирай зображення безпосередньо на тренувальному полі.
- Використовуй різне освітлення та положення камери.
- Не допускай значного дисбалансу між класами.
- Перевіряй модель на нових зображеннях, яких не було під час навчання.
- Не створюй надмірну кількість схожих класів.
- Якщо класифікатор розпізнає об'єкти неправильно, доповни набір даних і навчи модель повторно.

Пам'ятай: якість класифікатора значною мірою залежить від якості та різноманітності навчальних зображень.
