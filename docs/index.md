# Limelight 3A для FTC

Вітаємо в документації **Limelight 3A для FIRST Tech Challenge (FTC)!**

Цей посібник допоможе командам FTC налаштувати Limelight 3A, освоїти комп'ютерний зір та інтегрувати камеру в програму робота.

Тут зібрані інструкції, приклади та пояснення, адаптовані для використання Limelight 3A у FTC.

[Limelight 3A](https://docs.limelightvision.io/docs/docs-limelight/getting-started/limelight-3a) — це спеціалізована смарт-камера, оптимізована для змагань з робототехніки (зокрема FTC), яка забезпечує високошвидкісну обробку зображень, трекінг AprilTag та роботу з нейромережами без зайвого налаштування.
## Що ви знайдете в документації?

- **Початок роботи** — підключення Limelight 3A, перше налаштування та знайомство з інтерфейсом.
- **AprilTag** — розпізнавання міток, визначення їхнього положення, системи координат і локалізація робота на полі.
- **Color Detection** — налаштування розпізнавання кольорів та фільтрації об'єктів.
- **Neural Networks** — створення, навчання та використання власних моделей для розпізнавання об'єктів.
- **Програмування для FTC** — підключення Limelight до FTC SDK, робота з Java API та отримання даних із камери.

## Для кого ця документація?

Посібник призначений для учасників команд FTC, які хочуть використовувати Limelight 3A у своїх роботах. Він буде корисним як для початківців, так і для тих, хто вже має досвід програмування, робототехніки та комп'ютерного зору.

## Як користуватися посібником?

Рекомендуємо почати з розділу **«Початок роботи»**, після чого перейти до потрібної технології розпізнавання. Якщо ви плануєте використовувати Limelight у програмі робота, перегляньте розділ **«Програмування для FTC»**.

> **Мета цього проєкту** — зібрати зрозумілу та практичну документацію українською мовою, яка допоможе командам FTC ефективно використовувати Limelight 3A.

Документація постійно доповнюється та вдосконалюється.
