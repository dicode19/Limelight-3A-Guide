# Limelight-3A-Guide

Ласкаво просити до офіційного посібника та документації щодо налаштування й використання смарт-камери **Limelight 3A** у змаганнях з робототехніки **FIRST Tech Challenge (FTC)**.

Цей репозиторій містить структуровані інструкції, приклади коду та налаштування, які допоможуть твоїй команді швидко інтегрувати комп'ютерний зір у робота.

---

## 📚 Що увійшло до документації?

1. **Швидкий старт (Getting Started):** Підключення, апаратні характеристики та первинне налаштування камери.
2. **Кольорові та світлоповертаючі пайплайни (Color & Retroreflective):** Налаштування HSV-фільтрів та контурів для пошуку ігрових елементів.
3. **Пайплайни AprilTag та 3D-локалізація:** Використання міток, систем координат та технології MegaTag2 для позиціювання на полі.
4. **Нейромережі (Neural Networks):** Запуск моделей детекції та класифікації об'єктів на базі CPU.
5. **Програмування (Programming):** Приклади коду на Java (Android Studio) та робота з середовищем Blockly.
